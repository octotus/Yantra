# Sigil Mapping

Yantra uses engraved symbolic emblems for active calendar states. Lucide icons are acceptable placeholders where the icon matches the traditional symbol closely enough.

Lucide icons are licensed under the ISC License. Keep attribution in project notices before distribution.
